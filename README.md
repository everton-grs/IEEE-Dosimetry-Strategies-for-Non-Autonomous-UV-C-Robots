This repository contains all files required to reproduce the results presented in the article *“Dosimetry Strategies for Non-Autonomous UV-C Robots”*, including figures, raw data, and scripts.

## Repository Contents

### 1. Figures
- **Figures 1, 2, and 8:** High-resolution photographs.
  - Format: `.png`
  - Location: `/fotos/` directory
  - Usage: Directly included in the manuscript.

- **Figures 3 to 7:** Editable files created using **OriginLab** software.
  - Format: `.opju`
  - How to open:
    1. Download the Origin software at: [https://www.originlab.com/index.aspx?go=Products/OriginStudentVersion](https://www.originlab.com/index.aspx?go=Products/OriginStudentVersion)
    2. Go to `File > Open > path/filename.opju`
    3. The file will display:
       - `Book1`: worksheet containing raw data
       - `Graph`: corresponding plot or figure

### 2. Experimental Data
- **Figure 9 and Table I:** Refer to the manual counting of **Colony Forming Units (CFUs)** in Petri dishes.
  - File: `tabelaI-dados.txt`
  - Content: Raw data showing the number of colonies per experimental condition
